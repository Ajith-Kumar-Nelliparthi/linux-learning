## Day - 04

### Exercise-1
- Script that takes a number as input and prints whether it is positive, negative, or zero.

### Exercise-2
- Script that checks if a file exists. If yes, prints its contents; otherwise creates the file with default text.

### Exercise-3
- Script that compares two numbers provided as command-line arguments and prints whether the first is greater than, less than, or equal to the second.

### Exercise-4
- Script that checks if the user running it has write permission for a specified file and displays the result.

### Exercise-5
- Script that asks for a user's age and name. If the user is 18 or older and their name is "Admin", prints "Access granted"; otherwise prints "Access denied".
